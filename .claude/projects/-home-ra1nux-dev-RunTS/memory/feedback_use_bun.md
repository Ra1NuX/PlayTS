Use `bun` instead of `npm` for installing packages and running scripts.

**Why:** User preference — they use bun as their package manager.
**How to apply:** Always use `bun install`, `bun add`, `bun run` instead of `npm install`, `npm run`, etc. in both PlayTS and the landing page repos.
