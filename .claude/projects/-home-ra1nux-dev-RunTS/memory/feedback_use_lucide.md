Use Lucide icons (`lucide-react`) instead of `react-icons` for the app UI.

**Why:** Lucide has a consistent thin-line style that looks professional. The landing already uses Lucide.
**How to apply:** When adding or replacing icons, import from `lucide-react`. Don't mix icon libraries in the same view.
