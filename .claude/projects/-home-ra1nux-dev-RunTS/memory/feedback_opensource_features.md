Never remove existing functionality when adding Pro/premium features. The app is open source — free features must stay.

**Why:** Users rely on existing features (like BYOK API keys for AI). Premium features are additive, not replacements.
**How to apply:** Pro features (like AI proxy) should be an alternative path, not a replacement. If a user has their own API key, always let them use it directly regardless of plan.
